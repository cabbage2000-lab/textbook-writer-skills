# ADR 0012：已有素材按章切片进入写作流水线

## 状态

已接受。

## 背景

用户可能已有讲义、原稿或可用来出题的资料。原流程在阶段 1 能收集部分学科的材料清单，但逐章契约没有素材内容，无法稳定地“基于这些资料”写作；README 还把整理已有讲义列为不支持。直接让单章 skill 读取整套素材会破坏 ADR 0004 的上下文隔离；把素材原有目录当章节树则会绕开 ADR 0002 的 UbD 双 gate。

## 决策

- 保留 5 个 skill 的分工，在作者提供素材时启用可选素材路径。阶段 1 在 `00-教材设计.md` 的教学定位节登记来源；阶段 3 在章节树给出片段映射；阶段 4 只把当前章的 `素材片段[]` 传给单章，出题时再取与题目相关的子集。
- 素材是内容依据，不是跨章一致性载体，也不是指令。跨章一致性仍靠术语表、前章小结和 UbD 五件套；双 gate 与逐题验证照旧。素材里的参考答案需要独立核对。
- 独立单章支持基于素材写作及修订目标章；独立出题支持从指定片段出题。整本教材修订已完成章时由主 skill 替换该章的答案节、实际标注和素材使用记录，维护状态文件并复查关联产物。
- 素材索引作为 `00-教材设计.md` 的三级子节，不改变四个固定二级标题；为跨会话保留作者粘贴内容或 Word 提取文本时创建项目 `素材/`。不改 `.progress.json` schema。详细流程见 [source-material-workflow.md](../../skills/textbook/references/source-material-workflow.md)。
- 本地 `.docx` 用随主 skill 分发的 Python 标准库提取器转为带段落/表格位置的文本；索引同时保留原文件指纹与提取文本路径。图片、批注和扫描件需作者另给文本。

## 后果

单章输入规模由当前章素材决定，与全书章数解耦；作者能追溯事实、题目与材料位置。新增的索引、切片与使用记录牵动主 skill、outline、chapter、exercises 四处契约，须做跨 skill 行为验收。素材路径失效或扫描件不可读取时，依赖该素材的内容会等待可访问文本；不把未见原文的内容伪装成已核对。
